# Рубежный контроль №1 по ПиК ЯП

**Вариант запросов:** В  
**Предметная область:** №33 — «Строка данных — Таблица данных»

## Запуск

Нужен Python 3. Запустите программу из этой папки:

```bash
python3 main.py
```

Программа использует только стандартную библиотеку Python.

## Структура программы

- `DataRow` описывает строку данных: её идентификатор, название, количество заполненных значений и ID таблицы.
- `DataTable` описывает таблицу: её идентификатор и название.
- `DataRowTable` хранит пары ID строки и таблицы для связи многие-ко-многим.
- Списки `data_rows`, `tables` и `data_row_tables` содержат небольшие тестовые данные.

Связь **один-ко-многим** задаётся полем `table_id` в строке данных: у каждой строки одна основная таблица, а у таблицы может быть несколько строк. Связь **многие-ко-многим** задаётся отдельным списком `data_row_tables`: строку можно связать с несколькими таблицами.
